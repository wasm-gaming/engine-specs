# Usability scheme, `createInput()` and the engine app contract

2026-11-13 · phase 1 of play.germade `RECORD/2026-11-13.routes-engine-menus-and-shared-opfs.WIP.md`.

**Status:** approved by the owner (routes plan: "los menús de cada motor, los implemente cada motor …
siguiendo todos un esquema de usabilidad, especialmente con el manejo del gamepad"), being implemented.

## Why here
Every engine now ships its own app (start / load-game screen, pause menu, options), and the launcher
has its own menus. They must feel identical under a gamepad. engine-specs is the one package every
engine already depends on, so the scheme and its small runtime live here — no new shared dependency.

## What is added (still one file, still no runtime dependencies)

1. **The scheme** — `UX.md`, normative:
   - actions: `up down left right accept back menu more prev next`;
   - gamepad (standard mapping): A=accept, B=back, Start=menu, Select+Start=menu, Y=more, X=more,
     LB/RB=prev/next, d-pad and left stick=move; keyboard: arrows, Enter/Space, Escape/Backspace,
     Tab/V, Q/E (prev/next);
   - rules: one element always focused, focus shown as the white ring; Back goes up one level and, at
     the top of a game's menus, asks before leaving; Start opens and closes the pause menu; while a
     menu is open the game receives no input; hold-to-repeat after 380 ms every 110 ms.
2. **Runtime** in `src/engine-specs.ts`:
   - `UI_KEYMAP`, `UI_PADMAP`, `UI_REPEAT` — the mapping as data;
   - `createInput(options?)` → `{ on(listener) → off, suspend(), resume(), suspended, destroy() }`:
     keyboard (optionally capture-phase and swallowing mapped keys) + gamepad polling with
     key-like repeat and the Select+Start combo;
   - `nextFocus(from, candidates, direction)` — geometric (spatial) navigation between elements;
   - `UI_TOKENS` + `uiTokensCss()` — focus ring, radii, type faces, spacing as CSS custom properties.
3. **App contract** (types): `EngineAppHost` (`game`, `storage.namespace`, `assets` thunks, `input`,
   `exit()`), `EngineApp` (`mount(target, host) → Promise<EngineAppHandle>`), `EngineAppHandle`
   (`unmount()`), and the optional static `app` URL an SDK class may advertise.
4. **Tests**: `tests/ui.test.mjs` — key mapping, gamepad repeat and the combo with a fake clock and
   fake gamepads, `nextFocus` geometry. Version **0.4.0** (additive).
